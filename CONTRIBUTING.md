# Contributing to Alternative Credit Scoring Platform

Thank you for your interest in contributing!

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/durgacharan193/Credit-Scoring-Platform.git
   cd Credit-Scoring-Platform
   ```

2. Start the local mock server for fast frontend development:
   ```bash
   cd backend
   node src/mock-server.js
   ```

3. Run the Next.js frontend:
   ```bash
   cd frontend
   npm run dev
   ```

## Pull Request Guidelines

- Ensure all TypeScript code compiles (`npm run build`).
- Ensure unit and integration tests pass.
- Write descriptive, semantic commit messages (`feat:`, `fix:`, `docs:`, `test:`, `infra:`).
