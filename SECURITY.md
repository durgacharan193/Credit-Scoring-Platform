# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project:
- Please send an email directly to security@example.com instead of opening a public issue.
- Include a detailed summary, steps to reproduce, and any proof-of-concept material.
- We will acknowledge receipt within 48 hours and provide a timeline for resolution.
